抵達與移動

▼
03:00 - 10:00 抵達機場與報到。抵達日本後使用 KIOSK 自助通關。
10:00 - 12:00 搭乘 HARUKA 前往天王寺站。行李可寄放車站置物櫃。
🚃 導航：機場 → 天王寺

🏙️
天王寺周邊

▼
12:00 - 16:00 午餐後逛唐吉訶德、Uniqlo 買必需品。
有時間可去天王寺動物園或通天閣下走走。
16:00 搭車前往森之宮飯店 Check-in (16:00 後可入房)。

🏯
大阪城公園

▼
17:00 - 20:00 傍晚前往大阪城，拍攝黃昏與點燈後的景色。
晚餐 森之宮附近晚餐。回程順便買隔天早餐 (Daily YAMAZAKI)。

👘
清水寺周邊

▼
06:00 - 12:00 森之宮 → 京橋 → 七條 (京阪本線特急)。
轉乘 206 公車至清水道，步行至清水寺參觀。
🚃 導航：飯店 → 清水寺
12:00 在此區域享用午餐。

🎋
嵐山散策

▼
13:00 - 17:00 搭 202 公車至西大路三條 → 轉嵐電至嵐山。
逛渡月橋、竹林之道。

🌃
返回大阪

▼
17:00 - 24:00 阪急嵐山站 → 桂站 → 大阪梅田站。
可選擇在桂站或回到梅田/森之宮吃晚餐。
🚃 導航：嵐山 → 梅田

🥟
南京町 (中華街)

▼
09:00 - 12:00 森之宮 → 大阪車站 → 元町站。
逛南京町中華街。中午可吃 Oboya。
🚃 導航：飯店 → 元町

⚓
濱海樂園

▼
12:00 - 17:00 元町 → 神戶車站。
步行至濱海樂園 (Harborland) 逛街看海景。
晚餐 回神戶車站附近吃黑毛和牛燒肉 轟屋。
19:00 神戶車站 → 大阪車站 → 森之宮。

🛍️
梅田迷宮

▼
09:00 - 18:00 全日狂逛梅田商圈 (百貨/地下街)。
午餐於梅田解決。
🚃 導航：森之宮 → 大阪

🌃
心齋橋之夜

▼
18:00 - 24:00 搭乘御堂筋線：梅田 → 心齋橋。
晚餐 + 逛街。回程搭長堀鶴見綠地線回森之宮。

⛩️
住吉大社

▼
08:00 - 12:00 森之宮 → 天王寺。
轉乘阪堺電氣軌道至住吉，參拜住吉大社。
🚃 導航：天王寺 → 住吉

👜
臨空城 Outlet

▼
12:00 - 15:00 住吉大社 → 堺 (南海本線)。
轉乘至臨空城 (Rinku Town) 做最後衝刺。
🚃 導航：住吉 → 臨空城
15:00 搭乘電車前往關西機場報到。
